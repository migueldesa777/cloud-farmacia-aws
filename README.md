# 💊 Cloud Farmácia

Projeto desenvolvido como prática de desenvolvimento web, simulando uma plataforma de farmácia online com interface de usuários e backend estruturado.

## Estrutura do Projeto

- `backend/` → API da farmácia (Node.js, SQLite)  
- `frontend/` → Interface do usuário (HTML, CSS, JS)  
- `docs/` → Documentação e protótipos  
- `modelo-relatorio.md` → Relatório de entrega

## Tecnologias Utilizadas

- Node.js
- SQLite (simulado)
- HTML / CSS / JavaScript
