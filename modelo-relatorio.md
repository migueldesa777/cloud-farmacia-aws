# Relatório do Projeto Farmácia Virtual

## Objetivo
Criar uma plataforma fictícia de farmácia online para praticar conceitos de backend e frontend.

## Funcionalidades
- Listagem de produtos
- Cadastro de usuários (simulado)
- Login (simulado)
- Interface simples em HTML/CSS/JS

## Estrutura
- `backend/` → códigos do servidor, rotas e modelos
- `frontend/` → interface do usuário
- `docs/` → documentação e protótipos

## Considerações
O projeto é fictício e serve para estudo e apresentação de conceitos de computação em nuvem e desenvolvimento web.
